04 Philosophy

I’d rather build it than just talk about it.

  1. i.

    Ideas are cheap.

    Shipping something someone can click is the point.

  2. ii.

    Clear structure, honest design.

    No tricks. Layouts you can read, decisions you can follow.

  3. iii.

    Be kind to the next person.

    Code that doesn’t fight whoever touches it next — including future me.

  4. iv.

    Simpler wins.

    If it can be simpler, it should be.
